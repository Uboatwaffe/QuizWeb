# Security Policy

## Supported Versions

Only the section with :white_check_mark: are secure

| Version | Supported          | Description   |
|---------|--------------------|---------------|
| v1.0    | :x:                | REST API      | 
| v2.0    | :x:                | MVC           |
| v2.1    | :white_check_mark: | MVC           |
| v3.0    | :white_check_mark: | MVC in Docker |
